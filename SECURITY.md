# Security policy

## Report a vulnerability

When GitHub displays **Report a vulnerability** on the [NBi Security tab](https://github.com/Seddryck/NBi/security), use it to send the maintainers a private report. If the form is unavailable, [open an issue](https://github.com/Seddryck/NBi/issues/new) asking for a private contact. Keep vulnerability details out of that issue.

In the private report, include the affected NBi version, the component or file involved, the conditions needed to reproduce the behavior, and its impact. Remove credentials and private data from any examples.
